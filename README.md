# PHP-Basics-Exercise-3

This is an exercise based off the operators and conditional logic in PHP.

### In this exercise you will find the answers to 5 questions:
* A simple budget calculator that calculates your remaining balance and amount spent
* An age category check that determines if the given age is a child, teen, adult, or senior
* A simple interest calculator that calculates a 5% interest for R10 000 over 3 years
* A logical operator that checks if a user is eligible to vote and if they're registered or not
* A script that adds a discount based on the purchase amount
